# Project LOOP — Multi-Tenant AI Customer Feedback Intelligence Platform

Project LOOP is an enterprise-grade customer feedback analytics platform built to aggregate scattered customer signals across channels, extract AI-driven topic clusters, monitor sentiment trends, and generate executive Voice-of-Customer (VoC) reports.

---

## 🚀 Tech Stack

- **Framework**: Next.js 14 (App Router, Server Actions, API Routes) with TypeScript
- **Styling**: Tailwind CSS with custom design system color tokens
- **Database**: PostgreSQL (Neon Serverless compatible) with Prisma ORM
- **Authentication**: NextAuth.js (Auth.js) credentials provider with BCrypt password hashing & RBAC
- **AI / LLM Engine**: Anthropic Claude API (`claude-sonnet-4-6`)
- **Embeddings & Vector Search**: Voyage AI / HuggingFace embedding models with in-memory cosine similarity & pgvector schema support
- **Analytics & Data Vis**: Recharts (Area, Donut, Bar, Sparklines)
- **Validation**: Zod schema validation across all API endpoints

---

## ✨ Features Implemented

### 1. Multi-Tenant Architecture & RBAC
- **Workspace Isolation**: Every database query is strictly scoped by `workspaceId`.
- **Role-Based Access Control**:
  - `ADMIN`: Full management of feedback, themes, report generation, and team invitation/role assignment.
  - `ANALYST`: Can ingest feedback, trigger AI re-classification, manage themes, and generate reports.
  - `VIEWER`: Read-only access to dashboards, inbox, themes, and reports.

### 2. Feedback Ingestion
- **Manual Form**: Add individual feedback items with channel labels, customer tags, and reference IDs.
- **Bulk CSV Upload**: Smart CSV parsing (via `papaparse`) supporting bulk ingestion with per-row validation reporting.
- **Simulated Channels**: Native simulation for App Store reviews, Support tickets, and NPS survey feedback.

### 3. Feedback Inbox
- **Multi-Filter Engine**: Filter by search query, channel, sentiment (Positive/Neutral/Negative), status (New/Reviewed/Actioned), and theme IDs.
- **Status Workflow**: Interactive status transition actions (`NEW` → `REVIEWED` → `ACTIONED`).
- **AI Classification**: Real-time or manual re-classification using Claude API to determine sentiment score, feature area, rationale, and theme assignments.

### 4. Analytics Dashboard
- **Key Performance Indicators**: Total Feedback, Negative Sentiment %, Weekly New Volume, and Active Themes.
- **Interactive Data Vis**:
  - Daily Feedback Volume area chart with custom tooltips.
  - Sentiment Distribution donut chart with percentage breakdown.
  - Top Themes horizontal bar chart.

### 5. Themes & Trends
- **AI Theme Extraction**: Automatic assignment of feedback to existing themes or dynamically generated custom themes.
- **Spike Detection**: Visual highlight indicators for themes experiencing >30% volume growth over 30 days.
- **Sparkline Visualization**: Embedded weekly volume trendlines for each theme card.

### 6. Ask LOOP (Grounded RAG Q&A)
- **Semantic Vector Search**: Question embedding vector comparison against ingested feedback items.
- **Grounded Q&A**: Answers generated by Claude AI strictly constrained to context feedback items.
- **Verbatim Citations**: Interactive feedback cards linked as cited sources for every AI answer.

### 7. Voice-of-Customer Reports
- **Pre-Computed Statistics**: Automatic aggregation of period stats, sentiment shifts, and top theme deltas.
- **AI Narrative Generation**: Executive summaries, quote selections, and recommended product actions written by Claude AI.
- **Sharing & Export**: Printable/exportable PDF layout and shareable report link generator.

## 🛠️ Local Development Setup

1. **Clone & Install Dependencies**
   ```bash
   cd loop
   npm install
   ```

2. **Environment Configuration**
   Copy `.env.example` to `.env` (or `.env.local`) and configure:
   ```env
   DATABASE_URL="postgresql://user:password@localhost:5432/loop_db"
   NEXTAUTH_SECRET="your-32-character-random-secret"
   NEXTAUTH_URL="http://localhost:3000"
   ANTHROPIC_API_KEY="sk-ant-..."
   VOYAGE_API_KEY="pa-..."
   ```

3. **Database Migration & Seeding**
   ```bash
   npx prisma db push
   npx prisma db seed
   ```

4. **Start Development Server**
   ```bash
   npm run dev
   ```
